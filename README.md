# sentinel-argus
**Sentinel-Argus** is a Python-based command-and-control system that simulates a multi-sensor autonomous surveillance robot, integrating real-time sensor fusion, AI-driven threat assessment, and an interactive GUI for intelligent perimeter monitoring and control.

## Setup Instructions

1. Clone repo
git clone https://github.com/you/sentinel-argus.git
cd sentinel-argus

2. Create virtual environment
python3 -m venv sentinel_env

3. Activate it
source sentinel_env/bin/activate

4. Install dependencies
pip install -r requirements.txt

5. Run project
python main.py
